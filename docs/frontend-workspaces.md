# 前端工作区规范

本文是布局的唯一事实源。ADR 0006 只记录决策原因；spec 和 Issue 只引用本文。

## 布局

| 工作区 | 左侧 | 右侧 |
| --- | --- | --- |
| 学习 | 会话列表 | 当前会话的对话 |
| 资料 | AI 对话 | 资料列表与详情 |
| 组卷 | AI 对话 | 蓝图、草稿或试卷 |
| 作答 | AI 对话 | 试卷与当前答卷 |

学习区：

```text
┌──────────────────┬────────────────────────────────────┐
│ 会话             │ 当前对话                           │
│ [新建] [搜索]    │ 标题  [资料] [风格] [模型]         │
│ 会话列表         │ 消息                               │
│                  │ 上下文 / 附件                      │
│                  │ 输入框                       [发送]│
└──────────────────┴────────────────────────────────────┘
```

资料、组卷、作答区：

```text
┌──────────────────────┬────────────────────────────────┐
│ AI 对话              │ 任务内容                       │
│ 当前会话  [切换]     │ 当前对象  状态  [主操作] [更多]│
│ 消息                 │ 列表、正文、预览或反馈         │
│ 当前对象 / 选区      │                                │
│ 输入框         [发送]│                                │
└──────────────────────┴────────────────────────────────┘
```

- 学习区会话栏建议 `260–320px`；右侧对话填满剩余空间，不增加第三栏。
- 其他三区 AI 栏建议 `320–400px`；资源列表只能放在右侧局部导航、标签页或抽屉。
- 左栏可以收起，但必须保留会话、消息位置和输入草稿。
- 任务内容标题栏只放当前对象、必要状态、一个主操作和最多三个常用图标。
- 空状态最多两行文字，并提供一个直接动作。

## 工作区

### 学习

- 左侧提供新建、搜索、切换、重命名和删除会话。
- 右侧只显示当前对话；资料、来源和设置使用抽屉、弹层或消息内展开。
- 无会话时显示“开始新对话”和 `新建`。

### 资料

- 左侧 AI 可回答、整理或请求修改当前资料。
- 右侧显示资料列表和详情，主操作是 `上传资料`；上传文件保持只读，AI 修改先预览。
- 空状态使用“还没有资料”和 `上传资料`。

### 组卷

- 左侧 AI 是自然语言组卷和修改的首选入口。
- 右侧显示 `蓝图 / 草稿 / 试卷`；按状态提供 `确认蓝图`、`开始组题` 或 `发布试卷`。
- AI 修改题目时显示差异和 `应用 / 放弃`。

### 作答

- 左侧 AI 接收题目或选区；考试模式不得泄漏隐藏答案。
- 右侧显示试卷和答卷，区分 `完成作答`、`继续作答` 和 `提交批改`。
- 选区旁的“问 AI”打开左侧对话并附带上下文；没有试卷时显示 `去组卷`。

## 共同行为

- 四区共享当前学习会话；切换工作区不创建新聊天，也不丢失上下文。
- `普通`、`苏格拉底`、`章节速成`只改变聊天风格，不显示阶段、提示层级或强制步骤。
- 普通回答不修改任务内容；修改先生成预览，再由用户应用或放弃。
- 选中内容只加入下一条消息的上下文，不自动调用模型。
- 平板使用侧滑左栏；移动端学习区切换“会话 / 对话”，其他三区切换“AI / 内容”。

## 文案

- 工作区名称 2–4 字，按钮 2–6 字，状态 2–5 字，空状态标题不超过 10 字。
- 熟悉动作使用图标和 tooltip；确认、发布、提交、应用等关键命令保留短文字。
- 不显示营销口号、教程句子、JSON、operationId 或“解析锚点”等内部术语。
- 每个正常状态都有当前内容，每个空状态都有直接动作，不用装饰填充空白。

## 验收

1. 学习区左侧是会话列表，右侧是可发送消息的当前对话。
2. 资料、组卷、作答区左侧是 AI 对话，右侧是对应任务内容。
3. 自然语言组卷、资料修改和作答选区问答都作用于正确对象，且修改需要确认。
4. 切换工作区、会话、侧栏或移动视图不会丢失输入、选区和当前对象。
5. 页面没有教学阶段、长篇说明、无操作大空白或答案泄漏。
