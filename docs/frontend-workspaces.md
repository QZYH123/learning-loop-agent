# 前端工作区规范

本文是四个一级工作区的布局与交互主规范。实现与旧 Ticket 描述冲突时，以本文、`CONTEXT.md` 和 ADR 0003–0005 为准。

## 产品原则

- **Simple but useful**：用户优先说出目标，AI 负责理解和准备操作；界面只保留确认、查看和纠错所需的结构。
- **对话不离场**：学习、资料、组卷、作答四个工作区的左侧始终是 AI 对话，不因切换工作区变成功能列表。
- **内容可控制**：AI 可以回答和提出修改，但不会因为一条聊天消息直接覆盖右侧内容。
- **少字但不猜**：熟悉动作使用图标和 tooltip；不可逆或含义不明确的动作使用短文字。
- **右侧不是展板**：内容工作区必须有当前内容、明确空状态和上下文操作，不能只有说明文字或大面积留白。

## 固定布局

### 桌面端

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 科目 / 一级工作区导航                         模型          设置          │
├────────────────────────────┬─────────────────────────────────────────────┤
│ AI 对话栏                   │ 内容工作区                                  │
│ 320–420 px，可收起          │ min-width: 560 px，填满剩余空间             │
│                            │                                             │
│ 会话标题     [资料] [模型]  │ 当前对象标题   状态     [主要操作] [⋯]      │
│ ─────────────────────────  │ ─────────────────────────────────────────  │
│ 消息记录                   │ 当前资料 / 学习文档 / 蓝图 / 试卷 / 作答    │
│                            │                                             │
│                            │ 选区、预览、差异和反馈都在这里显示           │
│ ─────────────────────────  │                                             │
│ [当前选区或附件]           │                                             │
│ 输入框                 [↑] │                                             │
└────────────────────────────┴─────────────────────────────────────────────┘
```

布局规则：

- 顶部一级导航只切换工作区，不承载当前工作区的所有操作。
- AI 对话栏默认宽度建议 `360px`，允许在 `320–420px` 内调整；收起后保留一个展开图标。
- 内容工作区是页面主区域。其标题栏固定，正文独立滚动，异步状态不能让布局跳动。
- 会话列表通过对话栏标题旁的图标打开抽屉或弹层，不能占据整个左栏。
- 资料列表、蓝图列表、草稿列表和试卷列表属于右侧内容导航，可使用右侧内部窄栏、标签页或弹层。
- 不把任一整页包成浮动卡片，也不在卡片中继续嵌套卡片。

### 平板和移动端

- `768–1023px`：内容工作区默认全宽，AI 对话栏作为可固定的侧滑面板；选中内容后点击“问 AI”自动打开对话栏。
- `<768px`：使用“对话 / 内容”两个视图切换，不把两栏压在同一屏；切换时保留滚动位置、输入草稿、选区和当前对象。
- 移动端主要操作固定在内容标题栏或底部操作区；不能只在 hover 时出现。
- 复杂蓝图编辑可提示使用桌面端，但查看、自然语言组卷、确认、作答和提问必须可用。

## AI 对话栏

四个工作区使用同一个对话组件和同一会话记录，只改变当前内容上下文和可用工具。

### 必需区域

1. **标题栏**：会话标题、会话列表按钮、当前资料按钮、当前模型按钮、收起按钮。
2. **消息区**：用户消息、AI 消息、来源、模型快照、生成/失败/停止状态。
3. **上下文条**：显示当前右侧对象、选中文字、题目或附件；每项都可以移除。
4. **输入区**：多行输入、附件、发送/停止。输入框 placeholder 随工作区变化，但不显示长教程。
5. **对话风格**：`普通`、`苏格拉底`、`章节速成`使用紧凑选择器；它只改变提示或工具指令。

### 禁止行为

- 不显示“第 1/2/3 层提示”“启发中”“等待复述”等应用级阶段。
- 不用一排专用按钮强迫用户按 `开始 -> 尝试 -> 提示 -> 复述 -> 自测` 操作。
- 不因进入资料、组卷或作答工作区而清空聊天或更换成资源列表。
- 不自动把普通回答保存成资料、试卷或笔记。
- 不把内部术语、JSON、operationId 或状态机名称展示给用户。

### 自然语言操作

用户可以直接输入：

- “根据这三份资料出一套 90 分钟的期末卷。”
- “把第二题改简单一点，保留考点。”
- “解释我刚才选中的这句话。”
- “把这份资料整理成更好读的复习笔记。”
- “检查我的答案，但先不要给分。”

AI 回答分为两类：

- **回答**：直接进入消息记录，不改变右侧内容。
- **操作提案**：右侧显示预览或差异，并提供“应用”和“放弃”；应用后才产生新版本或状态变化。

## 内容工作区通则

内容标题栏至少包含：

- 当前对象名称；没有对象时显示短空状态标题。
- 必要状态，例如“解析中”“草稿”“已完成”“待批改”。
- 一个当前最重要的主操作。
- 最多三个常用图标操作，其余放入 `⋯` 菜单。

右侧不允许出现“只有一段说明文字，没有任何可执行操作”的空状态。空状态最多两行文字，并至少提供一个直接动作。

## 四个工作区

### 学习

左侧：

- AI 对话是主要内容，用户可自由提问或切换对话风格。
- `苏格拉底`只改变 AI 更倾向于反问、引导和检查理解的方式。
- `章节速成`只改变 AI 更倾向于先梳理范围、再按章节快速讲解的方式。

右侧：

- 显示当前选中的资料片段、AI 整理的学习文档、笔记或章节提纲。
- 没有内容时显示“选份资料开始”以及 `选资料` 主按钮；可以保留一个 `新建笔记` 图标按钮。
- 标题栏常用操作：切换当前文档、编辑、加入会话、导出；没有当前文档时不显示无效按钮。
- AI 生成的提纲默认先作为聊天回答；只有用户明确“整理成文档”时才进入右侧并保存。

### 资料

左侧：

- 始终显示 AI 对话。用户可以询问当前资料，也可以要求 AI 创建或编辑资料文档。
- 选中资料、版本或原文片段后，对话输入区显示相应上下文标签。

右侧：

- 右侧内部可以使用“资料列表 + 详情”的局部布局，不能把资料列表挪到左侧替换聊天。
- 标题栏主操作是 `上传资料`；辅助操作包括创建 AI 文档、加入会话、查看版本和更多菜单。
- 资料详情显示内容预览、原文位置和版本；“解析锚点”只作为内部字段，界面称为“原文位置”。
- 用户上传资料只读。要求 AI 修改时，创建一份 AI 文档或修改提案，并在右侧展示差异。
- 空状态使用“还没有资料”与 `上传资料`；支持格式放进文件选择器说明或 tooltip，不写成长段正文。

### 组卷

左侧：

- 始终显示 AI 对话。自然语言是新建蓝图和修改试卷的首选入口。
- 当前蓝图、草稿、选中题目或选区作为对话上下文，不要求用户重新描述对象。

右侧：

- 右侧内部提供 `蓝图 / 草稿 / 试卷` 三个真实视图或步骤；列表和历史记录放在右侧局部导航。
- 初始空状态显示“想出一套什么卷？”并把焦点放到左侧输入框；右侧保留 `导入蓝图` 或 `新建空白蓝图` 之一作为次要入口。
- 蓝图标题栏主操作：`确认蓝图`；草稿标题栏主操作：`开始组题` 或 `发布试卷`，按当前状态二选一。
- 题目操作使用图标：重试、编辑、删除、上移、下移；危险操作需要确认。
- 用户说“把第二题改简单”后，右侧显示差异预览；不能只在聊天里回复“已修改”。
- 右侧必须可直接查看题目、生成状态和失败原因，不能只展示蓝图/试卷数量。

### 作答

左侧：

- 始终显示 AI 对话。用户选中文字、题目区块、表格或整张图片后，可直接提问。
- 选区自动成为输入区上方的上下文标签；用户仍需发送问题，选中动作本身不调用模型。
- 考试模式下，AI 不得通过聊天泄漏未公开答案或解析。

右侧：

- 显示试卷列表和当前作答，但列表只能是右侧局部导航或抽屉。
- 标题栏常用操作：模式、保存/暂停、`完成作答`、`提交批改`；根据状态只显示当前可用项。
- `完成作答`与`提交批改`保持独立；完成后显示 `继续作答`。
- 选区旁出现一个小型“问 AI”浮动按钮；点击后打开左侧对话并保留选区。
- 反馈、解析和建议显示在对应题目附近，不用跨页面寻找。
- 没有已发布试卷时显示“还没有可作答的试卷”和 `去组卷`，不能只留空白。

## 文案规则

### 长度

- 一级工作区名称：2–4 个字。
- 按钮：2–6 个字，动词开头，例如“上传资料”“确认蓝图”“提交批改”。
- 状态：2–5 个字，例如“常识模式”“解析中”“待批改”。
- 空状态标题：不超过 10 个字；补充说明最多一行，不超过 24 个字。
- tooltip 可以更完整，但只解释动作结果，不介绍产品理念。

### 用词

| 不使用 | 改为 |
| --- | --- |
| AI 伴学导师与学科问答就绪 | 开始聊聊 |
| 学科知识图谱梳理 | 梳理重点 |
| 在左侧列表中选择资料查看解析锚点、历史版本，或点击上传新资料。 | 还没有资料 / 上传资料 |
| 解析锚点 | 原文位置 |
| 学习产物 | 笔记、提纲或试卷（按实际对象说） |
| 结构化修改提案 | 修改预览 |
| 编排运行 | 运行记录（仅开发设置页） |

### 图标与文字

- 收起、展开、搜索、上传、附件、发送、停止、重试、撤销、重做、下载使用熟悉图标并提供 tooltip。
- `确认蓝图`、`发布试卷`、`完成作答`、`提交批改`、`应用修改`等关键命令保留文字。
- 不使用只有文字的圆角胶囊代替熟悉图标；状态可以使用紧凑标签。
- 不使用装饰性图标填满空白。图标必须对应动作、状态或对象。

## 验收场景

1. 用户进入组卷工作区，不填写复杂表单，直接在左侧说“用当前资料出 20 道题”，右侧出现可确认蓝图。
2. 用户在右侧选中第二题并说“降低难度”，右侧出现修改预览，只有点击“应用”后试卷才产生新版本。
3. 用户在作答页选中一句题干，点击“问 AI”，左侧对话自动带上选区；考试模式不会泄漏答案。
4. 用户在资料工作区要求“把这份笔记整理得更清楚”，右侧出现 AI 文档差异，而不是静默修改上传文件。
5. 切换到苏格拉底或章节速成后，聊天风格改变，但界面不出现提示层级、固定阶段或强制动作按钮。
6. 四个工作区收起/展开左栏后，AI 对话、输入草稿、当前选区和右侧对象都不会丢失。
7. 每个右侧空状态都有一个直接动作；任一正常桌面视口不存在大面积无内容且无操作的区域。
8. 页面可见文案通过逐项检查：没有营销口号、内部术语、长教程或重复解释。
