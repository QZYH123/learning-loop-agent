# 将本地 CLI 学习循环改为浏览器个人学习工具

新产品以浏览器中的个人 AI 学习工具为方向，取代旧规格中面向技术学习者的本地 CLI 产品边界。第一版优先打通“资料或目标 -> AI 组题 -> 用户作答 -> 批改与薄弱点反馈”，问答和章节学习先提供轻量能力并共用同一套资料；没有用户资料时默认采用通用知识模式，有用户资料时默认采用资料严格模式，资料未覆盖的内容明确告知，只有用户主动允许时才补充模型通用知识；第一版不自动联网。产品先按单用户本地网页设计，按科目隔离资料、知识点、会话和试卷，并保留被引用的资料版本。资料上传一次后进入科目资料库，后台解析并建立可复用的来源索引；每次问答、组卷或选区提问只检索相关章节、页码、表格或图片，并返回来源位置，不重复发送全文。第一版优先使用结构解析和关键词/章节检索，不为引入资料库而强制增加复杂向量数据库。支持 PDF、DOCX、PPTX、Markdown、TXT 和图片资料；图片内容由具备视觉能力的模型理解，产品只负责文件处理、来源定位、缓存和能力适配，不在 MVP 自建 OCR/CV 系统。每道生成题必须带有答案、解析、考点和可复查的题目依据；缺少必要依据的题目标记为待核查，不作为可靠题目静默保存。组卷先把自然语言提示词解析为可确认的组卷蓝图，再采用增量组卷逐题生成；用户可以单独重试、删除或修改题目。试卷先生成结构化可编辑草稿，确认后保存；题目、选项、解析、分值和作答区域是固定区块，AI 或用户的修改必须可预览、可应用、可撤销。网页答题、打印和 PDF 导出共用统一版式，并提供考试模式和练习模式。整体采用双栏学习工作区：左侧是 AI 问答和学习操作区，右侧是试卷或学习文档；右侧选中的内容作为上下文发送到左侧对话，左侧回答默认不直接改写右侧文档，修改通过明确操作应用。主观题默认输出依据和改进反馈，分数可选。外层编排层按当前请求所选模型的接口能力选择文本或多模态输入；用户可以在会话中主动切换模型，系统在每条消息上显示实际使用的模型和配置，不承诺跨模型的批改标准一致，也不进行隐式自动切换。模型本身的思考和生成耗时不设产品硬门槛，编排层只减少重复处理、无效调用和界面等待。完整会话记录默认保存，并与资料库、试卷、笔记等学习产物分开管理；产物保留来源和会话链接，导出是明确的副本。资料不可用时停止新的检索并显示状态，不静默改写历史聊天或已保存产物。运行记录优先自动采集编排层指标，例如重复解析、重复调用、检索命中、结构化校验、重试、撤销和外层阶段耗时；答案正确率、引用准确率和主观题得分点覆盖率作为模型结果观测，用固定样例和抽样人工复核评估，不把它们混同为编排层性能门槛。这一选择牺牲了旧方案较窄、较容易实现的边界，换取对通用科目和实际学习场景的覆盖。
