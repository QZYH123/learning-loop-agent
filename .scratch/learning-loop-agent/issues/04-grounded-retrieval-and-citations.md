# 04 — 资料检索和来源引用

**What to build:** 让用户选择当前科目的资料并基于资料提问。系统只取相关内容交给模型，回答带可复查的来源位置；默认使用资料严格模式，资料没有覆盖时明确说明，不暗中补充模型知识。

**Blocked by:** 02 — 基础问答和模型切换；03 — 基础资料库

**Status:** ready-for-agent

- [ ] 用户可以为一次问答选择一个或多个资料来源
- [ ] 系统只把相关章节或文本片段发送给模型，不重复发送全部资料
- [ ] 回答展示来源资料和稳定位置，用户可以查看引用上下文
- [ ] 资料未覆盖问题时，资料严格模式明确说明无法依据资料回答
- [ ] 用户可以主动开启补充通用知识，补充内容与资料依据明确区分
- [ ] 检索和引用行为可使用假模型及固定资料稳定复现
- [ ] 自动化测试覆盖多资料选择、未命中、严格模式和来源失效
