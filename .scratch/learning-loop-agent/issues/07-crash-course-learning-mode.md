# 07 — 章节速成对话风格

**What to build:** 在同一学习会话中提供章节速成对话风格。AI 先确认学习范围和可用时间，再按章节或主题快速讲解；它不是必须先生成知识目录的独立工作流。

**Blocked by:** 04 — 资料检索和来源引用；06 — 苏格拉底对话风格

**Status:** ready-for-agent

## Contract

- [ ] 复用 `chat_style: crash-course`，不新增章节阶段状态机
- [ ] 普通消息接口支持章节速成风格，不要求调用专用生成接口
- [ ] 独立笔记或提纲只在用户明确要求保存时创建，并复用 AI 资料文档或学习文档提案契约

## Backend

- [ ] 章节速成风格通过提示或工具指令鼓励 AI 先确认范围、时间和目标，再快速讲重点
- [ ] AI 可以在聊天中使用简短目录组织回答，但应用不强制每轮返回固定知识点 JSON
- [ ] 资料未覆盖的内容继续遵守严格模式，不因“速成”静默补全
- [ ] 用户说“整理成笔记/提纲”后才生成可保存、可编辑的独立文档
- [ ] 切回普通或苏格拉底风格时保留完整对话和当前资料

## Frontend

- [ ] `章节速成`与其他对话风格出现在同一个紧凑选择器中
- [ ] 不创建独立的章节流程页、固定步骤条或必须逐项点击的目录
- [ ] 聊天回答可以引用右侧资料；明确保存后，右侧打开生成的笔记或提纲
- [ ] 用户可以继续自由追问、跳过章节或要求只讲某一部分

## Verification

- [ ] 测试章节速成使用同一消息接口和同一会话历史
- [ ] 测试严格模式未命中、风格切换和明确保存文档
- [ ] 浏览器检查用户不需要先理解目录生成流程即可开始学习

## Comments

- 原实现把章节速成建模为异步结构化产物生成；该接口可以作为兼容能力保留，但不再是主要用户入口，也不能决定前端布局。
