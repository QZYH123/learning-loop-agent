# 07 — 章节速成式学习

**What to build:** 根据选定资料生成可浏览的章节知识目录。每个知识点提供简短解释、关键点、来源和一个自测题，用户可以从目录跳转并在同一会话中继续追问。

**Blocked by:** 04 — 资料检索和来源引用

**Status:** ready-for-agent

- [ ] 用户可以从一个或多个资料生成章节知识目录
- [ ] 每个知识点包含简短解释、关键点、来源和自测题
- [ ] 用户可以在目录、知识点内容和问答之间顺畅切换
- [ ] 资料未覆盖的章节不会被模型静默补全
- [ ] 生成结果作为学习产物保存并回链到会话和资料版本
- [ ] 自动化测试覆盖目录生成、来源引用、跳转和保存行为
