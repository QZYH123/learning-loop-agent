# 37 — 明显坏题进入待核查

**Type:** task

**Status:** resolved

**Source:** 组卷蓝图产出可保存试卷。现有待核查几乎只看有没有资料依据；「以上都不对」、题干泄底、重复选项仍可能标成可靠题。

## 范围

做：在现有题目校验里给明显出题瑕疵打上 `needs-review`。
不做：新题库标准、新状态、拒绝保存、自动改题。

## 设计规定

- 走现有 `_validate_manual_question`，生成和手改共用。
- 选择题命中任一即待核查：选项为「以上都是 / 以上都不对 / all of the above / none of the above」、选项正文重复、正确答案正文出现在题干里。
- 依据仍然完整时也只改 `reliability` 和题注，不丢掉已有来源引用。
- 发布仍可用「接受待核查」；不把坏题直接 422。

## 验收标准

1. 把选项改成「以上都不对」后，草稿题状态为待核查。
2. 题干包含正确选项正文时为待核查。
3. 正常生成的 Limits 选择题仍是已生成 / reliable。

## Answer

`_validate_manual_question` 在结构校验之后检查选择题：凑选项套话、选项重复、题干含正确选项正文。命中则 `reliability=needs-review`，依据完整时只写题注，不改来源。生成和手改共用。
