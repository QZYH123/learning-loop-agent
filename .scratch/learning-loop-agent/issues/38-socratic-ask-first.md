# 38 — 追问引导默认先让人答

**Type:** task

**Status:** resolved

**Source:** ADR 0004：对话风格只是提示。现有指令已说不要先给完整答案，但仍偏软。要默认先让学习者作答；对方明确要求直接讲再讲完。

## 范围

做：加强 `chat_style: socratic` 的风格指令。
不做：阶段门禁、提示层级、专用按钮。

## 设计规定

- 指令要求默认先让学习者尝试作答或解释。
- 学习者明确说直接讲解、给答案、跳过引导或只要标准答案时，才完整作答。
- 不解析模型输出、不增加会话状态。

## 验收标准

1. 苏格拉底风格请求的模型提示含「先让学习者尝试作答」和「直接讲解」。
2. 现有「无阶段 JSON、可任意发消息」测试不回归。

## Answer

`_chat_style_instruction("socratic")` 改为默认先让学习者尝试作答；只有明确要求直接讲解、给答案或跳过引导时才完整作答。仍只是提示，无阶段状态。
