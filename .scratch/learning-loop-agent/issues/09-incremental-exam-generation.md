# 09 — 增量组卷和题目校验

**What to build:** 根据已确认的组卷蓝图逐题生成结构化试卷。每道题独立显示处理状态，可单独重试、删除或修改；只有带答案、解析、考点和题目依据的题目才能作为可靠题目保存。

**Blocked by:** 08 — 组卷蓝图确认

**Status:** ready-for-agent

- [ ] 试卷结构在题目生成前可见，题目按蓝图逐个进入处理状态
- [ ] 选择、填空、判断、简答、辨析和大题具有稳定结构
- [ ] Markdown、LaTeX、表格和图片可作为题目内容
- [ ] 每道题包含答案、解析、考点和资料来源或通用知识标记
- [ ] 结构或题目依据不完整时，该题标记为待核查
- [ ] 用户可以单独重试、删除或人工修改一道题
- [ ] 生成失败不会丢失其他已完成题目
- [ ] 自动化测试使用假模型覆盖成功、结构错误、重试和部分失败
