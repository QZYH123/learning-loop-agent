# 02 — 基础问答和模型切换

**What to build:** 在当前科目空间中提供基础 AI 问答。用户可以配置模型服务、发送消息、停止生成、继续会话并主动切换模型；完整聊天记录本地保存，每条 AI 消息显示实际使用的模型信息。

**Blocked by:** 01 — 应用壳和科目空间

**Status:** ready-for-agent

- [x] 用户可以配置并验证一个文本模型服务
- [x] 用户可以发送问题、看到生成状态、停止生成并收到回答
- [x] 没有用户资料时，回答明确标注为通用知识模式
- [x] 用户可以在同一会话中主动切换模型，后续消息使用新模型
- [x] 每条 AI 消息记录并显示实际使用的服务商和模型
- [x] 完整聊天记录在重新打开应用后仍然存在，并支持显式删除
- [x] 自动化测试使用可控假模型验证消息、切换和持久化行为

## Comments

- 实现（技术栈已调整为 FastAPI 后端 + 浏览器前端）：`backend/app/domain.py` 管理模型服务和按科目隔离的会话状态；`backend/app/model_client.py` 调用 OpenAI-compatible `/chat/completions`；`backend/app/generation.py` 编排验证、发送、失败和停止；`frontend/` 提供模型配置、验证、模型切换和问答界面。
- 测试：`pytest -q`（15 项全部通过），假模型覆盖验证、消息、切换、停止和本地恢复。
