# 15 — 编排层观测和固定评估

**What to build:** 为已经完成的问答、资料检索、组卷、批改、选区问答、修改和导出流程增加可用的编排层观测，并运行固定评估样例。观测重点是软件是否可靠高效，不把模型生成速度或模型知识能力误算成编排层问题。

**Blocked by:** 02 — 基础问答和模型切换；04 — 资料检索和来源引用；09 — 增量组卷和题目校验；10 — 客观题答题和考试/练习模式；11 — 主观题批改反馈；12 — 选区问答；13 — AI 修改试卷和版本恢复；14 — 统一版式和导出

**Status:** ready-for-agent

- [ ] 自动记录资料解析、检索、模型调用、结构校验、重试、撤销和导出的阶段结果
- [ ] 可以发现重复资料解析和无必要的重复模型调用
- [ ] 外层阶段耗时与模型生成耗时分开记录
- [ ] 运行记录不意外复制完整资料、凭据或无关敏感内容
- [ ] 固定样例覆盖引用准确性、答案泄漏、题目结构和主观题得分点
- [ ] 模型结果观测与编排层硬指标在报告中明确分开
- [ ] 自动化测试验证事件完整性、隐私边界和固定评估可重复运行

## Comments

- 后端已实现持久化编排运行、阶段计数器、请求指纹、外层耗时与模型等待分离、脱敏事件、固定评估套件和可重复评估运行；评估结果明确分开编排指标与模型结果观测。前端观测报告界面尚未接入。
