# 10 — 客观题答题和考试/练习模式

**What to build:** 让用户在线完成选择、填空和判断题，并在考试模式或练习模式下获得符合预期的反馈。作答和批改记录要能保存并在重新打开试卷后恢复。

**Blocked by:** 09 — 增量组卷和题目校验

**Status:** ready-for-agent

- [ ] 用户可以作答选择、填空和判断题并保存进度
- [ ] 选择和判断按标准答案判断，填空允许配置的同义答案和格式差异
- [ ] 考试模式在提交前隐藏答案和解析
- [ ] 练习模式允许按题请求即时反馈
- [ ] 暂停和重新打开试卷后恢复已填答案和当前模式
- [ ] 提交后的结果显示正确答案、解析和题目依据
