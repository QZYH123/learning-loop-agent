# 11 — 主观题批改反馈

**What to build:** 让用户提交简答、辨析和大题答案，并获得得分点、遗漏点、推理过程和改进建议。系统可以提供可选分数，但必须保留反馈依据并避免把主观判断伪装成绝对结论。

**Blocked by:** 09 — 增量组卷和题目校验

**Status:** ready-for-agent

- [ ] 用户可以提交并保存简答、辨析和大题答案
- [ ] 反馈分别展示命中的得分点、遗漏点、推理问题和改进建议
- [ ] 用户可以选择是否显示建议分数
- [ ] 每次反馈记录题目依据、用户答案和实际使用的模型
- [ ] 模型返回信息不完整时明确标记待核查，不伪造确定结论
- [ ] 自动化测试使用固定评分要点覆盖完整、部分、错误和无法判断答案
