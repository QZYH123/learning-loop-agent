# 22 — 简洁文案、上下文操作和视觉完整性

**What to build:** 按布局主规范减少解释性文字，用熟悉图标和短命令完成主要操作，并保证内容可用。

**Blocked by:** 18 — 学习会话与任务工作区布局；19 — 模型配置、API 格式和手动发现；20 — AI 生成的资料文档；21 — 作答完成标记和批改解耦

**Status:** ready-for-agent

**Copy and layout source of truth:** `docs/frontend-workspaces.md`。

## Copy

- [ ] 删除营销口号、能力宣告和面向实现者的说明文字
- [ ] 工作区标题 2–4 字，按钮 2–6 字，状态 2–5 字，空状态标题不超过 10 字
- [ ] 空状态说明最多一行且不超过 24 字，具体格式支持等信息放入 tooltip 或文件选择器
- [ ] 禁止显示“AI 伴学导师与学科问答就绪”“学科知识图谱梳理”“在左侧列表中选择资料查看解析锚点、历史版本，或点击上传新资料。”
- [ ] 使用“常识模式”“原文位置”“修改预览”等用户能直接理解的词，不显示“解析锚点”“学习产物”“结构化提案”“编排运行”等内部术语
- [ ] placeholder 根据工作区使用一句直接问题，例如“想学点什么？”“想出一套什么卷？”“要解释哪一题？”

## Controls

- [ ] 收起、展开、搜索、上传、附件、发送、停止、重试、撤销、重做和下载使用熟悉图标并提供 tooltip
- [ ] `确认蓝图`、`发布试卷`、`完成作答`、`提交批改`、`应用修改`等关键命令保留短文字
- [ ] 不使用带文字的圆角矩形代替已有熟悉图标，不用装饰性图标填空
- [ ] 所有下拉、分段控件和图标按钮都可实际操作，并具有 focus、disabled、loading 和 error 状态
- [ ] 下拉菜单同步 `aria-expanded`，支持方向键、Enter 和 Esc

## Task content

- [ ] 资料、组卷和作答区的右侧标题栏都有当前对象、必要状态、一个主要操作和最多三个常用图标操作
- [ ] 操作按当前状态出现，不展示一排不可用按钮
- [ ] 无当前对象时至少提供一个直接动作，禁止整屏空白或只有说明文字
- [ ] 内容区域使用标题、分隔线和留白建立层级，减少卡片套卡片
- [ ] 固定工具栏、选区菜单、反馈和正文在桌面及移动端不重叠

## Visual and responsive

- [ ] 四个工作区可以有克制的语义色，但不能让页面被单一蓝色、紫色、米色或深色主题支配
- [ ] 一级导航激活项使用细微标记，不使用大面积高亮块
- [ ] 卡片圆角不超过 `8px`，不重新引入粗边框、歪斜卡片、硬阴影或装饰性光球
- [ ] 移动端完整支持聊天、资料查看、自然语言组卷和作答；复杂蓝图表格可以提示桌面端编辑
- [ ] 文本、按钮和固定工具栏在常见桌面、平板和移动视口无溢出、遮挡或布局跳动

## Verification

- [ ] 对所有可见中文做一次逐项审查，删除口号、长教程、内部术语和重复说明
- [ ] 用 Playwright 检查四个工作区的桌面、平板和移动截图
- [ ] 测试键盘导航、焦点状态、下拉关闭、侧栏恢复和选区菜单
- [ ] 检查每个右侧空状态都有直接动作，每个非空状态都有合理的上下文工具栏
- [ ] 检查控制台无重复监听、未捕获异常和布局错误

## Comments

- “少文字”不是删除必要动作。优先删解释和口号，保留能让用户完成任务的短命令、状态和错误信息。
