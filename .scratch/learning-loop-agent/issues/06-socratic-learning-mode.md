# 06 — 苏格拉底式学习

**What to build:** 在资料依据问答上提供苏格拉底式学习。系统一次只推进一个问题，要求学习者先尝试，再按需要给出逐步提示、纠错、复述要求和变式自测，并保存完整学习过程。

**Blocked by:** 04 — 资料检索和来源引用

**Status:** ready-for-agent

- [ ] 用户可以从目标和选定资料启动苏格拉底式会话
- [ ] 系统一次只展示一个需要用户回应的学习动作
- [ ] 用户尝试前不会默认泄漏完整答案
- [ ] 提示从概念方向逐步变得具体，用户可以主动要求直接解释
- [ ] 纠错包含资料依据、错误点和下一步行动
- [ ] 会话支持复述检查和一个短变式自测
- [ ] 自动化测试覆盖正确回答、误解、缺少前置知识和直接解释请求
