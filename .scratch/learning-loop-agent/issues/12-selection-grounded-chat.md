# 12 — 选区问答

**What to build:** 在左侧 AI 问答、右侧结构化试卷的双栏工作区中，允许用户选中题干、选项、解析、表格或整张图片，并让左侧 AI 针对选区回答，同时保持试卷内容不被自动改写。

**Blocked by:** 02 — 基础问答和模型切换；09 — 增量组卷和题目校验

**Status:** ready-for-agent

- [ ] 用户可以在右侧选择文字区块或整张图片并发起提问
- [ ] 选区旁显示紧凑的“问 AI”入口，点击后打开左侧对话并带上可移除的上下文标签
- [ ] 仅选择内容不会自动调用模型，用户可以补充自己的问题后再发送
- [ ] 左侧对话明确显示本次问题关联的选区
- [ ] 模型收到选区、所在题目和可用来源信息
- [ ] AI 回答不会未经确认修改右侧试卷
- [ ] 选区问答作为完整聊天记录的一部分保存
- [ ] 自动化测试覆盖文字、图片、选区失效和切换题目

## Comments

- 后端已实现固定文档版本的文字/图片选区校验，把题目、内容块和引用上下文提交给聊天生成，并保证消息创建不修改试卷；过期选区返回 `CHAT_SELECTION_INVALID`。前端必须在作答工作区保留左侧 AI 对话，不能把试卷列表放到左侧替代聊天。
