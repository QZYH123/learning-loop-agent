# 08 — 组卷蓝图确认

**What to build:** 让用户用自然语言描述组卷要求，系统解析并展示可编辑的组卷蓝图。用户可以确认科目、考纲、资料范围、题型、题量、难度和分值，确认前不会开始生成题目。

**Blocked by:** 04 — 资料检索和来源引用

**Status:** ready-for-agent

- [ ] 用户可以用自然语言描述题型、题量、考纲、难度和分值要求
- [ ] 系统把要求解析为结构化且可编辑的组卷蓝图
- [ ] 题量、分值和总分矛盾时明确提示用户修正
- [ ] 用户可以选择资料严格模式、通用知识模式或补充通用知识
- [ ] 用户确认蓝图前不触发题目生成
- [ ] 已确认蓝图可以保存、重新打开和再次调整
- [ ] 自动化测试覆盖正常解析、缺少信息和约束冲突
