# 05 — PDF、DOCX、PPTX 和图片资料

**What to build:** 扩展资料库以支持 PDF、DOCX、PPTX 和图片。用户能看到解析状态并基于这些资料问答；图片内容直接交给具备视觉能力的模型理解，不支持图片的模型必须明确提示用户更换。

**Blocked by:** 02 — 基础问答和模型切换；03 — 基础资料库

**Status:** ready-for-agent

- [ ] 用户可以上传 PDF、DOCX、PPTX 和常见图片格式
- [ ] 文档保留页码、章节、表格或幻灯片等可引用位置
- [ ] 图片和包含图片的资料可以作为问答上下文
- [ ] 系统按模型接口能力判断是否支持图片，不按服务商名称硬编码
- [ ] 不支持图片时不静默降级，并提供可理解的更换模型提示
- [ ] 已处理文件可以复用缓存，相关请求只发送必要页面或图片
- [ ] 自动化测试覆盖各格式成功、失败、缓存和模型能力分支

## Comments

- 后端已支持 PDF、DOCX、PPTX 和常见位图解析，保存页码、表格、幻灯片、图片锚点与原始图片资源；模型视觉能力来自显式配置，不支持图片时返回 `IMAGE_INPUT_UNSUPPORTED`。前端上传与状态呈现尚未接入。
