# 18 — 四工作区对话优先布局

**What to build:** 学习、资料、组卷和作答四个一级工作区统一使用“左侧 AI 对话栏 + 右侧内容工作区”。自然语言是提问、组卷、解释和编辑的首选入口；资源列表和流程控件不能替换 AI 对话。

**Blocked by:** 16 — API 契约和工作流状态基线；17 — 多学习会话和显式资料上下文

**Status:** ready-for-agent

**Layout source of truth:** `docs/frontend-workspaces.md`、`CONTEXT.md` 的“AI 对话栏/内容工作区/双栏工作区”和 ADR 0003。

## Contract

- [ ] 四个工作区复用同一会话消息、消息上下文、临时附件、选区和模型快照契约
- [ ] 当前工作区、右侧对象和选区只改变消息上下文，不创建四套互不相通的聊天记录
- [ ] AI 对右侧内容的修改使用现有提案、预览和应用接口，普通消息没有修改副作用
- [ ] 不为静态统计卡片、功能说明或纯前端布局增加后端聚合字段

## Shared frontend shell

- [ ] 桌面端左侧 AI 对话栏宽 `320–420px`，右侧内容区最小宽 `560px` 并填满剩余空间
- [ ] AI 对话栏包含会话标题、会话抽屉入口、资料、模型、消息、上下文标签和输入框
- [ ] 会话列表通过抽屉或弹层打开，不能长期占据整个左栏
- [ ] 资料、蓝图、草稿、试卷和作答列表放入右侧局部导航、标签页或抽屉
- [ ] 四个工作区的 AI 对话栏都可收起，并分别记住状态；展开后保留输入草稿和滚动位置
- [ ] 右侧标题栏始终包含当前对象、必要状态、一个主要操作和最多三个常用图标操作
- [ ] 右侧空状态最多两行文字，并至少有一个直接动作；禁止无按钮的大面积留白
- [ ] 平板使用可固定侧滑对话栏，移动端使用“对话/内容”切换并保留状态

## Learning workspace

- [ ] 左侧直接显示 AI 对话，不以会话列表作为默认主内容
- [ ] 对话风格使用 `普通 / 苏格拉底 / 章节速成` 的紧凑选择器，不显示阶段或提示层级
- [ ] 右侧显示当前资料片段、笔记、提纲或 AI 学习文档
- [ ] 右侧无内容时显示“选份资料开始”和 `选资料`，可以保留一个新建笔记图标

## Sources workspace

- [ ] 左侧保持 AI 对话，选中资料、版本或原文后在输入框上方显示上下文标签
- [ ] 右侧内部显示资料列表和详情，主操作为 `上传资料`
- [ ] 右侧提供创建 AI 文档、加入会话、版本和更多操作，但按上下文隐藏无效按钮
- [ ] 用户用自然语言要求编辑时，右侧显示修改预览；用户上传资料保持只读
- [ ] 界面使用“原文位置”，不向用户展示“解析锚点”术语

## Exam studio workspace

- [ ] 左侧保持 AI 对话，用户可以直接用自然语言描述整套组卷要求
- [ ] 右侧使用 `蓝图 / 草稿 / 试卷`真实视图或步骤，并显示当前内容而非数量卡片
- [ ] 蓝图阶段提供 `确认蓝图`，草稿阶段按状态提供 `开始组题`或`发布试卷`
- [ ] 题目重试、编辑、删除和排序使用紧凑图标操作
- [ ] AI 修改题目或整卷后，右侧显示差异以及 `应用 / 放弃`，不能只在聊天里声称完成

## Practice workspace

- [ ] 左侧保持 AI 对话，不以已发布试卷列表替换聊天
- [ ] 右侧显示试卷局部导航和当前作答，提供模式、暂停、完成、继续作答和提交批改
- [ ] 用户选中文字、题目、表格或整张图片后出现紧凑的“问 AI”入口
- [ ] 点击“问 AI”打开左侧对话并附带可移除的选区标签，选中本身不调用模型
- [ ] 考试模式下聊天和选区问答都不能泄漏尚不可见的答案或解析
- [ ] 没有可作答试卷时显示“还没有可作答的试卷”和 `去组卷`

## Verification

- [ ] 从四个一级导航分别进入工作区，左侧第一屏都是可发送消息的 AI 对话
- [ ] 在组卷工作区输入“用当前资料出 20 道题”，右侧出现可确认蓝图
- [ ] 在作答工作区选中题干并问 AI，左侧收到准确选区上下文且右侧作答不被改写
- [ ] 在资料工作区要求 AI 编辑文档，右侧出现差异预览并等待明确应用
- [ ] 桌面、平板和移动视口不存在遮挡、溢出、不可恢复的收起状态或无操作大空白
- [ ] 切换工作区、会话和右侧对象不会丢失未发送输入、选区或上下文

## Comments

- 旧描述“资料、组卷和作答工作区不改变现有布局性质”已废弃。它导致这些工作区的左侧被实现成资料、蓝图和试卷列表，违背自然语言优先的产品目标。
- 提交 `07088ed` 的四工作区前端实现不满足本轮修订后的左侧对话栏要求，需要按本文重新收敛。
