# 18 — 学习会话与任务工作区布局

**What to build:** 实现 `docs/frontend-workspaces.md` 定义的学习会话布局和任务工作区布局。

**Blocked by:** 16 — API 契约和工作流状态基线；17 — 多学习会话和显式资料上下文

**Status:** ready-for-agent

**Source of truth:** `docs/frontend-workspaces.md`。

## Acceptance

- [ ] 四区共享当前会话、资料上下文、附件、选区和模型快照
- [ ] 桌面、平板和移动端布局符合主规范
- [ ] 会话管理、自然语言任务操作和资源导航都可用
- [ ] 普通消息不修改右侧内容；AI 修改必须预览后应用
- [ ] 右侧标题栏只显示当前对象、状态、主操作和少量常用操作
- [ ] 每个空状态都有直接动作，不出现无操作的大面积留白
- [ ] 移动端学习区切换“会话 / 对话”，其他三区切换“AI / 内容”
- [ ] 切换工作区、会话或侧栏不会丢失输入、选区和当前对象
- [ ] 考试模式下 AI 不泄漏隐藏答案或解析

## Comments

- 旧描述“资料、组卷和作答工作区不改变现有布局性质”已废弃。它导致这些工作区的左侧被实现成资料、蓝图和试卷列表，违背自然语言优先的产品目标。
- 提交 `07088ed` 的四工作区前端实现不满足本轮修订后的左侧对话栏要求，需要按本文重新收敛。
- ADR 0003 已被 ADR 0006 替代。
- 当前前端的学习区布局正确；资料、组卷和作答仍把资源列表放在左侧，尚未满足本 Issue。
