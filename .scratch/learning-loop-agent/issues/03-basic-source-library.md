# 03 — 基础资料库

**What to build:** 让用户在科目空间中上传和管理 Markdown、TXT 资料。资料以卡片显示处理状态和版本，处理结果可以被后续多个会话和试卷复用，删除或变更资料不会静默改写历史记录。

**Blocked by:** 01 — 应用壳和科目空间

**Status:** ready-for-agent

- [ ] 用户可以上传、查看和删除 Markdown、TXT 资料
- [ ] 资料卡片显示文件名、状态、版本和最近处理时间
- [ ] 重复打开资料不会重复解析未变化的内容
- [ ] 资料内容变化后产生新版本，旧版本引用保持可识别
- [ ] 资料失败或不可用时显示明确状态，不影响其他资料
- [ ] 不同科目默认不能看到或使用彼此的资料
- [ ] 自动化测试覆盖上传、解析缓存、版本变化和删除行为
