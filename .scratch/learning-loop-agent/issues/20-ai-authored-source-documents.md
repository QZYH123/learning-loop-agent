# 20 — AI 生成的资料文档

**What to build:** 允许用户明确要求 AI 创建或编辑项目资料文档。普通 AI 回答仍然只是会话消息，不自动保存为学习产物或资料。

**Blocked by:** 16 — API 契约和工作流状态基线；03 — 基础资料库；17 — 多学习会话和显式资料上下文

**Status:** ready-for-agent

## Contract

- [ ] 复用 Issue 16 定义的 AI 资料文档、版本和修改提案契约
- [ ] 明确 AI 生成来源标记和上游引用结构

## Backend

- [ ] 只有用户明确要求创建资料时才创建 AI 资料文档
- [ ] AI 资料文档默认进入当前项目资料库，并标明 `AI 生成`
- [ ] 用户上传资料保持只读，AI 不直接修改用户上传内容
- [ ] 编辑 AI 资料文档先生成结构化修改提案
- [ ] 用户应用提案后创建新版本，支持查看和恢复
- [ ] AI 资料文档可以被显式加入会话并参与检索
- [ ] 严格模式引用 AI 资料时明确显示其来源性质，并保留可用的上游引用

## Frontend

- [ ] 普通聊天消息不显示“保存为学习产物”的入口
- [ ] 资料工作区左侧始终是 AI 对话，用户可直接说“整理成笔记”或“修改当前文档”
- [ ] 右侧标题栏提供明确的“创建 AI 文档”操作，作为自然语言入口之外的直接操作
- [ ] 资料页右侧区分用户上传资料和 AI 生成资料文档
- [ ] 编辑结果在右侧显示修改前后差异，并提供应用和放弃操作
- [ ] 用户上传资料只读；要求编辑时明确创建 AI 文档或副本，不让用户误以为原文件已被改写
- [ ] 不增加新的一级工作区

## Verification

- [ ] 测试普通回答不会创建资料
- [ ] 测试显式创建、修改提案、版本恢复和来源标记
- [ ] 测试 AI 资料文档被加入会话后的检索和引用

## Comments

- 左侧不能实现成“用户资料 / AI 文档”列表栏；列表属于右侧内容导航，左侧保留可发送消息的 AI 对话。
- 2026-08-23：已有文档时主操作是「修改当前」；可查看旧版本并「恢复此版」。生成文档改到更多菜单。
