# 14 — 统一版式和导出

**What to build:** 使用同一份结构化试卷数据生成网页答题、打印预览和 PDF。三种呈现必须保持题目顺序、编号、选项、分值、公式、图片和作答区域一致，同时允许用户导出明确的副本。

**Blocked by:** 09 — 增量组卷和题目校验；10 — 客观题答题和考试/练习模式；13 — AI 修改试卷和版本恢复

**Status:** ready-for-agent

- [ ] 网页、打印预览和 PDF 使用同一份试卷内容和顺序
- [ ] Markdown、LaTeX、表格和图片在三种呈现中可读且不重叠
- [ ] 题目、选项、分值和作答区域在分页后保持完整
- [ ] 考试模式导出不会意外包含隐藏答案和解析
- [ ] 带答案版本必须由用户明确选择
- [ ] 导出文件被明确视为副本，不暗示与应用内试卷双向同步
- [ ] 自动化测试和视觉检查覆盖典型文理科试卷及多页分页
