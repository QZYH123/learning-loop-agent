# 36 — 错题在后来做对后退出列表

**Type:** task

**Status:** resolved

**Source:** 练习闭环收口。Issue 30 的错题投影只保留最近一次答错，同一题后来做对、或同一考点后来做对，都不会退出。再练只会让列表变长。

## 范围

做：错题投影按最新反馈判断当前是否仍算错；同一考点在更晚的已反馈作答中不再算错时，该题从该考点分组退出。
不做：间隔重复、复习日程、错题手工标记、新存储。

## 设计规定

- 仍是 `GET /api/subjects/{subject_id}/missed-questions` 的只读投影，不改契约字段。
- 同一 `(exam_id, question_id)` 取最新带反馈的作答：最新一次不再算错，则整题退出。
- 同一考点：若更晚的作答里，带该考点的题不再算错，则该题从该考点分组拿掉；没有任何考点时整题退出。
- `_recent_missed_knowledge_points` 继续读同一套收集结果。
- 考试模式未完成的作答不参与投影。

## 验收标准

1. 同一试卷再做一份并做对后，该题不再出现在错题列表。
2. 新试卷上同一考点后来做对，旧卷该考点下的错题退出。
3. 现有跨卷聚合、去重、无答案泄漏测试不回归。

## Answer

`_collect_missed_questions` 改为先按 `(exam_id, question_id)` 取最新反馈；最新一次不再算错则整题退出。同一考点若被更晚的正确反馈覆盖，该题从该分组拿掉。`_recent_missed_knowledge_points` 仍读同一套结果。考试模式未完成的作答不参与。测试覆盖同卷再做对、跨卷同考点做对。
